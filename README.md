# Concept-driven UX

コンセプトからアプリの体験を設計・改善するための Codex スキルです。既存機能の目的、利用者の行動と得られる結果を捉え、維持・変更・統合・削減の選択肢を比較します。初回と反復利用、情報の優先順位、全体のバランスやテンポも扱います。

## コンセプトを判断軸にする

ここでのコンセプト理論は、届けたい体験を明確にし、その目的から具体的な設計へ落とし込む方針です。特定の原典や提唱者への準拠を示すものではありません。

| 原則 | レビューで問うこと | 変更する例／維持する例 |
| --- | --- | --- |
| 目的から仕様を評価する | 誰のどの場面で、行為が望む結果につながるか | 読書を中断せず記録したいなら、保存前の詳細分類の必須化を見直す。後から探す手がかりは残す |
| 必要な行為の役割を守る | 負担を減らすことで、体験の価値も失わないか | 想起練習が目的なら、回答を思い出す入力や自己評価は、タップ数だけを理由に削らない |
| 要素同士の関係を見る | 情報・操作・演出を通したときにも目的を支えるか | 結果を隠す演出は順序を見直す。結果を読めて任意で楽しめる祝賀は維持できる |

現行仕様や過去の設計判断は、現状を知り、妥当性を再評価するための根拠です。**現在のユーザーの明示指示、守るべき契約、確認済みの制約を優先し、現行仕様そのものを自動的に変更禁止にはしません。** 変更の実行は依頼された範囲に限ります。

## インストール

このリポジトリを取得し、`skills/concept-driven-ux` フォルダを Codex のスキルディレクトリ（通常 `~/.codex/skills/`）にコピーしてください。同名の既存スキルがある場合は、内容を確認してから置き換えてください。Codex のスキル一覧を更新するには、セッションの再起動が必要な場合があります。

## 使い方

Codex で、対象と希望する範囲を添えて依頼します。

> `$concept-driven-ux` を使って、このアプリの既存機能と初回体験を見直して。まずは設計案まで。

> `$concept-driven-ux` を使って、この画面の操作を改善し、実装と検証まで進めて。

広い改善ではコンセプトを軸に対象を選びます。特定の修正やレビューのみの依頼は、その範囲に絞ります。

## 3つのスキルと資料

依頼の種類で入口が分かれ、連携はスキル名と「審査依頼パック」の形式で行います。

```text
体験の設計・改善の依頼
  → concept-driven-ux（本体）
      ├─ 全体のバランス審査 → experience-balance と連携
      └─ 独立審査と記録 → independent-review と連携（審査依頼パック）
バランスだけの審査 → experience-balance
審査だけの依頼 → independent-review
資料：docs/manual-snapshot.md（由来を示す保存版。現行手順が優先）
```

## 利用環境と進められる範囲

審査の要否は変更の区分に比例させます。独立審査が必要な区分では、開始時に、別の審査者を利用できるか、作者の自己評価や他担当の合否を含まない入力を用意できるかを確認します。

| 区分 | 審査 | 単独環境・分離を確認できない場合 |
| --- | --- | --- |
| 機械的（誤字・リンク切れ等、意味や表示を変えず差分で正しさを確認できる） | 不要。自己確認と一行記録 | そのまま進められる |
| 軽微（意味や流れを保つ細部修正） | 独立審査、または時間差自己審査 | 時間差自己審査を明示して進められる |
| 通常・大きな変更 | 分離した独立審査が必須 | 調査・設計案・自己チェック・検証計画まで。独立審査は未実施とし、実装を保留 |

別エージェントを起動しただけでは独立審査済みにはしません。時間差自己審査は独立審査として記録しません。既存の独立審査・承認が対象版・目的・範囲に有効なら、その根拠を確認して再利用できます。ユーザーの実装許可だけで独立審査の代用はできません（機械的の自己確認と軽微の時間差自己審査は、区分の規則として定めた経路であり、独立審査の代用ではありません）。詳しくは[審査環境の確認](skills/independent-review/references/review-protocol.md#開始時に審査環境を確認する)を参照してください。

実装やテストの成功だけで、人間による体験の改善を確認したとは扱いません。[回帰評価](evaluations/README.md)には架空の入力と判定条件を用意しています。

## 内容

- `skills/concept-driven-ux/SKILL.md` — スキルの入口と手順
- `skills/concept-driven-ux/references/` — 既存体験の評価、コンセプト達成の最終照合
- `skills/experience-balance/` — 全体のバランスとテンションカーブを審査する独立スキル（concept-driven-ux と連携）
- `skills/independent-review/` — 設計成果物の独立審査と記録のスキル（審査依頼パック、区分に比例した審査、差し戻しの反復条件を含む）
- `docs/manual-snapshot.md` — 設計マニュアルの保存版（スキル本体とは分けた由来資料）
- `skills/concept-driven-ux/agents/openai.yaml` — Codex 向け表示情報
- `evaluations/` — 架空の入力による回帰評価の手順と判定条件
- [CHANGELOG.md](CHANGELOG.md) — スキルの版と変更履歴（現在の版は 0.3.0）

マニュアルは 2026 年 10 月 2 日の保存版を基に、公開用の参照先を調整し、`docs/` に資料として置いています。保存原文と、その運用を具体化した現在の手順を区別しています。このリポジトリで共通手順を管理し、配布先固有の参照先や包装は分けて扱います。
