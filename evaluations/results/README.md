# 評価結果の記録

版ごとに、このフォルダへ実施結果を保存する。結果が保存されていない版は「評価実施済み」とは扱わない。

現在の版（0.3.0）の結果は未保存である。0.2.0 以前について、PR の本文等で実施が述べられたことはあるが、このリポジトリ内に照合できる結果記録は保存されていない。

## 記録の書式

```text
対象の版（コミット）とスキル版：
実施日時と実行環境：
担当とモデル：
ケースIDと試行回：
対象スキル：
入力と環境条件：
判定（合格／不合格／未確認）と根拠：
実際のファイル差分への参照：
未確認事項：
```

内部ログや個人情報は入れない。担当が他ケースの結果を受け取った試行は採点対象から外し、その旨と再実施の結果を分けて記録する。
