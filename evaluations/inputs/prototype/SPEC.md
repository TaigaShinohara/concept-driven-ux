# SessionFinish v1：限定試作
コンセプト：学習を終えた人が結果を理解して、次の行動を自分で選び、達成感を持って終えられる。

- 架空の学習結果は「10問中8問正解、次回の復習3問」。実データ・通信・永続保存・外部ライブラリは使わない。
- 一つのローカルHTMLで、通常の結果表示と、結果の下に任意で祝賀を開く案を比較する。結果と終了操作は常に見える。祝賀は閉じられ、自動遷移しない。
- 結果の理解と終了操作を演出で隠さない。動きは静的表現でもよい。
- 未知：任意の祝賀が達成感を高めるか、繰り返し使うと煩わしいか。人間の観察は未実施。この試作は比較に使うためのもので、本採用は依頼していない。
- 観察方法：同じ架空の結果で両案を触り、結果を説明できるか、終了操作を迷わず選べるか、祝賀をどう感じるかを確認する。今回は試用準備と構造確認まで。
- 終了条件：ローカルHTMLを作成し、結果・任意表示・閉じる・終了操作の構造を検証して止める。実アプリへ反映しない。
