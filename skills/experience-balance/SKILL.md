# 全体と同じレイヤーの要素間のバランスを審査する

個々の機能・画面・演出が魅力的でも、組み合わせた体験が目的に合うとは限らない。**個別の合格の足し算で全体を合格にしない。** 上位のコンセプトに照らし、同じ抽象度の要素を横断して、何を優先し、どこで強さを残し、何を控えるかを判断する。

広い改善では主要な構成と代表的な利用の系列を比較する。指定された狭い修正では、変更要素と、情報・操作・強弱の関係が変わる周辺だけを確認する。全機能・全状態・全レイヤーの網羅を開始条件にしない。

## 使い方（単独利用と連携）

このスキルは単独でも、concept-driven-ux の一部としても使える。単独利用では、要素間の関係の審査と指摘までを行い、機能の追加・削減や対象選定そのものは行わない。審査の進め方（作成者と別の担当による独立審査、判定と記録）は independent-review スキルの審査手順に従う。バランスの問題が機能の要否に及ぶ場合は、その判断を concept-driven-ux 側へ返す。

## 1. 比較する集合と守る価値を決める

今回選ぶレイヤー、同じ抽象度の要素、利用場面、版を示す。要素ごとの上位目的を確かめ、どの価値・判断・行為を優先するか、残すべき良さと山場の役割を先に記す。

| 選ぶレイヤー | 同じ抽象度で比較する例 | 問う関係 |
| --- | --- | --- |
| L1 コンセプト | 同じ体験内で掲げる価値・体験目標 | 優先順位が明確か。複数の目標が競合したときに何を守るか |
| L2 全体と周辺 | 主要機能同士、または利用の各段階同士 | 役割・比重・順序が目的に合うか。重複や分断、山場の集中はないか |
| L3 同一機能 | 対象機能の画面同士、状態同士、または操作の各段階同士 | 情報と行為がつながるか。通常・結果・失敗などの差と流れが成立するか |
| L4 細部 | 同時表示する情報同士、操作同士、または連続・反復する反応同士 | 重要度と目立ち方が合うか。強さ・長さ・頻度が相互にどう作用するか |

表のすべてを確認する必要はない。一つの比較で機能とボタンなど抽象度の違うものを混ぜない。異なるレイヤーへの因果は、比較結果を上位の目的へ戻す根拠として説明する。未確認の集合を全体合格に含めない。

## 2. 比較できる材料をそろえる

案件の既存資料へ次をまとめ、審査者が同じ組み合わせを再現・参照できるようにする。新しい台帳や全資料の転記は不要である。

- 選んだ同じレイヤーの要素一覧と役割。現在の優先順位、強く扱う理由、残したい価値。
- 代表的な同時表示と、利用開始から終了までの系列。初回だけでなく、反復で関係が変わる場面も必要な範囲で含める。
- 各場面で必要な情報、判断、次の操作と、それが必要になる時点。
- 演出・反応の強さの比較、発生条件、順序、頻度、長さ、重なり、操作への影響。測定値と推定を分ける。
- 画面・操作・仕様・コード・利用観察の参照と版。観察事実、設計仮説、人間未確認を分ける。

単体の静止画や最も映える場面だけでは時間の関係を判断しない。画面の並び、状態遷移、動画、操作できる成果など、今回の問いを確認できる材料を選ぶ。資料にない頻度や感情を補って事実にしない。

## 3. 空間・時間・反復の関係を具体的に比較する

審査者は「派手すぎる」「バランスが悪い」で止めず、どの要素同士が、どの場面で、目的をどう支えるか・損なうかを示す。

| 比較する関係 | 確かめること |
| --- | --- |
| 情報の優先順位と目立ち方 | 今必要な結果・説明・操作と、装飾・副次情報の位置、面積、コントラスト、動きを並べる。後者が前者を必要な時点で読めなくしたり、選べなくしたりしないか |
| 情報を伝える順序と演出 | 判断材料が届く前に次の選択を求めていないか。重要な変化を演出が覆わないか。説明・結果・手応え・次の行為の順序と重なりに役割があるか |
| 通常の反応と山場 | 日常の小さな行為と意味のある節目を並べ、強さ・長さ・内容の差がその価値に合うか。山場のために残す強さ、集中する場面、余韻や終了の役割を説明できるか |
| 連続する場面の強弱 | 前後を含む系列で、期待・集中・達成・落ち着きの意図と実際の表現を比べる。複数の山場が競合して、必要な理解や区切りを失っていないか |
| 頻度・長さと反復 | 発生頻度と一回の長さを合わせて見る。通常利用で何度待ち、何が重なるか。初回の驚きがなくても結果や手応えが伝わるか。慣れ・疲労・嬉しさの変化は人間で確かめる |
| 重複と配分 | 似た役割の機能・説明・反応が、同じ情報や行為を繰り返し要求していないか。統合・削減・配置変更でも必要な価値を守れるか |

空間と時間を別々に合格にして終えず、重要情報が出る瞬間に別の強い反応が重なるなど、両者の関係も確かめる。関係が今回変わらない項目は、有効な根拠を参照して省略できる。

強い表現や複数の山場それ自体を不合格にしない。強さを一律に下げたり、決まったテンション曲線へ当てはめたりせず、コンセプトと場面に合う差・配分・順序を選ぶ。固定秒数、共通スコア、指摘数のノルマで判断しない。

例：一つずつは魅力的なカットシーンでも、通常の達成から節目まで毎回同じ強さなら、節目を際立たせる意図が成立するか比較する。結果を読む必要がある時点で演出が文字を覆うことを確認したなら、その構成は不合格にできる。「疲れる」「山場が嬉しくない」は観察がなければ仮説として保留する。結果を先に見せる、通常の反応を短くする、節目の強さを残す案などを同じ系列で比べる。

## 4. 根拠で判定し、関係を含めて差し戻す

independent-review スキルの審査手順（担当と独立審査）に従い、作成者と別の担当が必要な専門範囲を審査する。設計の合否と人間の体験確認を別々に記録する。

- **合格**：選んだ集合・場面で、優先順位と関係が目的に合う根拠がある。残す強さ・良さと有効範囲も示す。個別合格や欠陥の未発見だけでは足りない。
- **不合格**：必要な時点の情報・判断・操作を妨げる、役割や状態を誤って伝える、目的に必要な区切りを失うなど、関係が目的を損なう具体的根拠がある。単なる好みで必須修正にしない。
- **保留**：関係の判断に必要な材料がない、または理解・疲労・嬉しさ・反復による慣れなどを人間で未確認。何を観察すれば判断できるか示す。AIの見立てで感情を確定しない。

設計上成立していることと、人間への効果が未確認なことは併記できる。本採用の保留と、その未知を確かめる試作の開始を区別し、技術・操作・構成・人間への効果を検証する条件は審査手順に従う。未解決の必須修正を、人間で試すことだけで免除しない。

差し戻しには、固定IDとともに次を付ける。

1. 関係する同じレイヤーの要素、場面・系列、対象版。
2. 守る目的と、それを損なう関係の根拠。観察した事実と未確認の仮説。
3. 成立する代案と残す価値。配置・順序、通常反応と山場の配分、発生条件、統合・削減などから必要なものを比べる。
4. 必須修正か改善提案か、担当、確認方法と解消条件。人間未確認なら、観察する行動・感想と判断条件。

解消は修正箇所だけでなく、変化した要素間の関係を同じ場面・系列で再確認する。影響しない有効な判定は引き継ぎ、資料審査を機械的に繰り返さない。期待した差が出なければ、表現の強さだけでなく、内容・行為・機能の役割や対象選定へ戻る。
